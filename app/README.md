# Streamlit app (coming soon)

The app will let a hospital manager:

1. **Predict:** enter or select a hospital's six experience scores and see its predicted recommend rate.
2. **Test what-ifs:** move sliders to see how improvements are associated with changes in the recommend rate.
3. **Benchmark:** see which hospital type it belongs to and how it compares with peers.

Run locally with:

```bash
streamlit run app/app.py
```
